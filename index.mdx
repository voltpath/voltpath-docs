VoltPath gives you programmatic access to European electricity market data: cross-border power flows, day-ahead prices, and the derived metrics built on top of them. Every endpoint is an HTTP GET that returns JSON, ready to drop into a dashboard, analytics pipeline, or trading model.

## What you can query

- **Prices** — day-ahead electricity prices per bidding zone
- **Flows** — cross-border power flows, classified by type (convergence, congestion, counter-intuitive, outage)
- **CI share** — how often flows run counter to price signals, by zone or border
- **Import / export** — net energy moved in and out of each zone

See [Bidding Zones](/concepts/bidding-zones) for zone codes and [Flow Types](/concepts/flow-types) for how classification works.

## Quickstart

```bash
curl 'https://api.voltpath.ai/api/v1/prices?zone=DE&datetime_from=now-7d&datetime_to=now&resolution=1D'
```

Every response shares one envelope shape:

```json
{
  "meta": { "resolution": "1D", "resolved_datetime_from": "...", "resolved_datetime_to": "..." },
  "data": [{ "datetime": "2026-08-19T00:00:00", "bidding_zone": "DE", "price_mwh": 82.45 }]
}
```

See [Response Format](/concepts/response-format) for the full spec, or the [API Reference](/api-reference/introduction) for every endpoint.

## Authentication

None required. Query any endpoint without an API key or token.
